# 30일간의 생존 (30 Days of Survival)

> ⚠️ **안내**: 이 코드는 인간의 아이디어를 기반으로 AI를 통해 작성되었습니다.

[English Version](./README.md)

Python과 Pygame-ce를 사용하여 개발된 오픈월드 좀비 아포칼립스 생존 게임입니다. 생존 스탯을 관리하고, 아이템을 제작하며, 은신처의 방어도를 높이고 야간 습격에 맞서 구조대가 도착할 때까지 30일 동안 살아남아야 합니다.

---

## 주요 특징

* **절차적 월드 생성 및 청크 시스템**: 심플렉스 노이즈 기반의 절차적 맵 생성으로 다양한 바이옴(도시, 주거지, 산림, 병원구역, 군사기지, 밀밭 등)과 도로망이 동적으로 구축됩니다.
* **건물 내부 탐색**: 주택, 상점, 학교, 병원, 공장에 진입하여 냉장고, 선반, 서랍장, 군용 상자 등의 가구를 루팅할 수 있습니다. 어두운 곳에 숨어 있는 은신형 좀비를 조심하세요!
* **야간 습격(Raid) 시스템**: 매일 밤(7일 주기로 더 거대한 호드 출현), 좀비 무리가 은신처를 습격합니다. 바리케이드 재료를 사용해 방어력을 높이거나 직접 맞서 싸워 은신처를 지키세요.
* **생존 스탯 및 은신**: 체력, 허기, 갈증, 스태미나, 스트레스 스탯을 실시간으로 관리해야 합니다. LCTRL 키로 앉아 은신하면 좀비의 감지 범위가 50%로 감소하고 발자국 소음이 나지 않습니다.
* **데이터 드리븐 인벤토리 및 크래프팅**: 무게 제한과 드래그 앤 드롭을 지원하는 격자형 인벤토리 시스템이 제공됩니다. 붕대, 개조 손전등, 함정, 바리케이드, 장거리 무전기 등 필수 생존 템을 제작할 수 있습니다.
* **NPC 대화 및 임무(퀘스트)**: 필드에서 상인, 군인, 생존자들과 상호작용합니다. 아이템을 거래하거나 구조 및 수집 임무를 수행할 수 있으며, 화면 우측의 실시간 퀘스트 HUD로 현황을 확인합니다.
* **다국어 및 오디오 시스템**: 한국어와 영어 다국어 번역을 완벽 지원하며 몰입감 있는 클래식 스타일의 효과음이 포함되어 있습니다.
* **세이브/로드 기능**: F5 빠른 저장 기능과 5일 주기 자동 저장 시스템이 제공됩니다.

## 설치 및 실행 방법

### 요구 사양
Python 3.8 이상 버전이 필요합니다.

### 실행 순서
제공된 배치 파일(`.bat`)을 실행하거나 터미널을 통해 실행할 수 있습니다.

1. 저장소를 클론하거나 다운로드합니다.
2. Windows 환경의 경우 `run.bat` 파일을 실행하면 자동으로 의존성 라이브러리가 설치되고 게임이 시작됩니다.

수동으로 실행 시:
```bash
pip install -r requirements.txt
python src/main.py
```

## 조작 방법

* **W, A, S, D** / **방향키**: 플레이어 이동
* **LSHIFT**: 스프린트/달리기 (스태미나 소모)
* **LCTRL**: 앉기/은신 (이동 소음 및 감지 범위 절반 감소)
* **마우스 좌클릭**: 공격 (무기에 맞춰 휘두르거나 발사)
* **E**: 상호작용 / 가구 탐색 / 건물 진입 및 나가기 / NPC 대화
* **I**: 인벤토리 열기/닫기 (좌클릭: 사용, 드래그: 장착/해제, 우클릭: 버리기)
* **C**: 크래프팅 창 열기/닫기
* **F5**: 빠른 저장
* **ESC**: 일시정지 및 메뉴 열기
